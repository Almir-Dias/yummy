# 🍽️ Yummy - Curadoria Inteligente de Restaurantes

O **Yummy** é um aplicativo mobile que utiliza a geolocalização do usuário para encontrar restaurantes locais e, de forma inteligente, sugere opções de cardápio personalizadas com base na **temperatura ambiente** em tempo real. 

O objetivo do projeto é unir conveniência e contexto, adaptando a experiência de busca de alimentos ao clima do momento (como sugerir pratos quentes em dias frios ou opções leves em dias de calor).

> **Status do Projeto:** 🚀 Concluído (Desenvolvido de forma colaborativa/em grupo)

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído integrado pelas seguintes tecnologias:

*   **Backend:** Ruby on Rails
*   **Frontend:** JavaScript, HTML5, CSS3
*   **Integrações (APIs Externas):** 
    *   API de Geolocalização (para mapeamento de posição do usuário)
    *   API de Clima/Tempo (para checar a temperatura local em tempo real)

---

## 🎯 Principais Funcionalidades

*   📍 **Geolocalização Ativa:** Identifica a localização do usuário para buscar os estabelecimentos mais próximos de forma automatizada.
*   🌤️ **Sugestões por Clima:** Algoritmo dinâmico que analisa a temperatura ambiente e filtra os tipos de culinária que mais combinam com o clima do dia.
*   📱 **Interface Mobile:** Desenvolvido com foco na experiência do usuário em dispositivos móveis (Mobile First), visando usabilidade e agilidade.
